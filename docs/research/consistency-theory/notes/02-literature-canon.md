## Lane E verdict (binding for the report)
1. Linear time-age Δ(t)=t−u(t) is the WRONG primitive for repository review freshness: anti-correlated with staleness at low change rates (dormant repo: age grows, review perfectly authoritative; 50 trivial commits: near-zero age, version lag 50).
2. Commit distance (b) is the right shape and is NOT novel: Version AoI (buyukates2021) instantiated on git, with two genuine wrinkles: (i) git history is a DAG not a monotone counter (merge-base/first-parent conventions needed); (ii) the "version" is the digest equivalence class [headSha, config-digest, changed-files], not commit count. Classification: USEFUL (existing lit) + PROPOSED_EXTENSION (application to review supervision).
3. Event-triggered vs periodic: legitimate STRUCTURAL analogy (poll = periodic observer; digest change = event; debounce = dwell time / min inter-event time); no transferable quantitative theorems. Change-triggered > cron-triggered at equal worst-case latency = the one licensed qualitative claim.
4. CUSUM/change detection NOT_APPLICABLE to hash equality (noise-free observation ⇒ no threshold optimization). Becomes relevant only for noisy channels (remote mirrors, sync lag, mtime heuristics).
5. Peak-AoI accounting legitimately bounds evidence staleness: detection latency (≤ poll interval + debounce) + run time. Renewal-reward gives average detection latency under Poisson assumption.
6. Kaul et al. buffer insight: single-run-per-event + dedupe = buffer-size-1 replace-on-new policy — the genuine AoI transfer.
