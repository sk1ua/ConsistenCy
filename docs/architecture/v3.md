# ConsistenCy v3 Architecture

ConsistenCy v3 is a **Repository-Native Agent Harness OS** built in TypeScript. It provides an evidence-driven code review infrastructure where deterministic analysis runs first, and optional LLM agents operate as a capability-restricted explanation and synthesis layer.

## 2. Core Architectural Components

### 2.1 Kernel Security & Authorisation (`@consistency/kernel`)
- **CapabilityBroker**: Sole issuing and enforcement authority for Capabilities. Default-deny. Performs per-call authorisation on every syscall attempt.
- **SyscallGateway**: Enforces authorization before calling trusted handlers. Refuses direct execution of `dispatch = "intent"` operations (`github.publish`, `repo.write`).
- **EffectClass vs DispatchPolicy**:
  - `EffectClass`: `"pure" | "read" | "revertible" | "commit"`
  - `DispatchPolicy`: `"direct" | "intent"`
  - `llm.invoke` = `commit` / `direct` (executed inline by trusted Ring 1 driver)
  - `github.publish` & `repo.write` = `commit` / `intent` (routed through `CommitCoordinator`)

### 2.2 Execution & Process Model
- **KernelScheduler**:
  - Cooperative admission control (`maxRunningAgents` concurrency limit).
  - States: `NEW`, `READY`, `RUNNING`, `WAIT_LLM`, `WAIT_TOOL`, `WAIT_IO`, `WAIT_AGENT`, `WAIT_HUMAN`, `SUSPENDED`, `SUCCEEDED`, `FAILED`, `CANCELLED`.
  - FIFO fairness among equal priorities; expired deadlines are cancelled before admission.
- **AgentControlBlock (ACB)**:
  - Kernel process metadata recording priority, lineage, `logicalRing` (`0 | 1 | 3`), `executionDomain` (`"in-process" | "worker-thread" | "child-process"`), and capability descriptor references.

### 2.3 Context VM & Evidence
- **ContextVM**:
  - Text-first immutable `ContextPage`s identified by SHA-256 `contentHash`.
  - `ContextImage` overlay with page residencies (`PINNED`, `HOT`, `COLD`, `EVICTED`).
  - `WorkingSet` projection for render-time token estimation.
  - Copy-On-Write (COW) page-table snapshots for agent forks.
- **Evidence Engine**:
  - Grounding evidence produced by deterministic analyzers (PR-4 Style & Secret analyzers, Python stdio engine).
  - Immutable canonical SHA-256 fingerprints over provenance and location.

### 2.4 CommitCoordinator & Durable Outbox
- **CommitCoordinator**:
  - Upstream authorization gate for irreversible external mutations (`github.publish`).
  - Idempotency key deduplication; computes SHA-256 `payloadHash`.
  - Holds no credentials or handles; hands `CommitIntent` to host Outbox sink.

### 2.5 Child-Process Sandbox (`packages/kernel/src/sandbox/`)
- Isolates untrusted 3rd-party plugins into Node child processes (`child-process`).
- Environment allowlist excludes parent secrets (`process.env` never inherited).
- Versioned RPC protocol (v1) over IPC channel.
- Server-side principal & capability binding: raw `CapabilityHandle` never sent to child.
- `SandboxAgentBridge` propagates sandbox failures/crashes/timeouts to `KernelScheduler` agent states.

## 3. Runtime Observability & Task Manager

- Route: `/runs/:runId/runtime`
- API Endpoints:
  - `GET /api/runtime/runs`
  - `GET /api/runtime/runs/:runId`
- Exposes `RunRuntimeSnapshot`:
  - Process tree, ACB states, `WAIT_LLM` / `WAIT_TOOL` pending operations.
  - WorkingSet token estimates and ContextVM page residency distribution.
  - Capability fingerprints (NO raw handles `cap_<64hex>`).
  - Truthful 6-dimension security guarantees.

## 4. Invariant Matrix

| Concept A | ≠ | Concept B | Architectural Boundary |
| --- | --- | --- | --- |
| Coeffect | ≠ | Authorization | Coeffect declares intent; CapabilityBroker authorizes syscalls |
| Logical Ring | ≠ | Execution Domain | Ring 3 agents may run in-process or child-process |
| Service Ring | ≠ | Caller Permission | Ring 1 drivers are mediated; agents never touch driver objects |
| Context Possession | ≠ | Authorization | Having a ContextPage grants no syscall permissions |
| ACB Capability Ref | ≠ | Authorization | ACB stores metadata fingerprints; handle checked per call |
| Cordis Fiber ACTIVE | ≠ | Authorization | Fiber state is a harness detail; Kernel authorizes syscalls |
| EffectClass | ≠ | DispatchPolicy | `llm.invoke` is commit/direct; `github.publish` is commit/intent |
| child-process | ≠ | Full OS Containment | Process memory & env isolated; OS filesystem/network not contained |
