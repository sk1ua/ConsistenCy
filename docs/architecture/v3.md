# ConsistenCy v3 Architecture Specification

> **Canonical Architecture Document**: The primary and comprehensive architecture specification is located at [docs/architecture.md](../architecture.md).

ConsistenCy v3 is a **Repository-Native Agent Harness OS** built in TypeScript:

$$\text{ConsistenCy v3} = \text{Kernel} + \text{Cordis Harness} + \text{Evidence Engine}$$

---

## 2. Key Subsystems

- **CapabilityBroker (`@consistency/kernel`)**: Sole issuing and enforcement authority. Default-deny. Performs 8-step authorization on every syscall.
- **SyscallGateway (`@consistency/kernel`)**: Enforces authorization before invoking handlers. Directly executes permitted read/pure operations; routes mutation operations (`github.publish`, `repo.write`) through `CommitCoordinator`.
- **KernelScheduler (`@consistency/kernel`)**: Cooperative admission control (`maxRunningAgents`), deterministic priority FIFO, deadline cancellation.
- **Context VM (`@consistency/kernel`)**: Immutable `ContextPage`s (SHA-256 `contentHash`), `ContextImage` overlays with residency (`PINNED`, `HOT`, `COLD`, `EVICTED`), COW page tables for forks, `WorkingSet` token estimation.
- **Evidence Engine (`@consistency/kernel` + `@consistency/plugins-builtin` + `engine/`)**: Grounding evidence with pinned `EvidenceProvenance` (`repository`, `sha`, `analyzer`, `analyzerVersion`) and canonical SHA-256 fingerprints.
- **Cordis Harness (`@consistency/harness-core`)**: Reactive dependency injection, fiber lifecycle, and coeffects. **Coeffect $\neq$ Authorization**.
- **Child-Process Sandbox (`packages/kernel/src/sandbox/`)**: Isolates plugin memory and parent environment secrets via explicit allowlists. Communication via versioned RPC over IPC.

For complete architectural details, security invariants, and runtime models, see [docs/architecture.md](../architecture.md).
